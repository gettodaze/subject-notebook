# Subject Notebook

A lightweight Obsidian plugin for switching between colored project notebooks, optional homepages, and a shared native Kanban. Each note keeps its notebook color; a colored status indicator identifies your main notebook.

The development preview requires desktop Obsidian 1.14.5+ with the Bases core plugin enabled. Start with a separate test vault.
